# CharForge Toolkit

Reusable deterministic geometry, rigging, motion diagnostics, secondary physics and layered-face methods. Original code is MIT. This is a set of experimental building blocks: it does not promise exact likeness, arbitrary anatomy, or an accepted character from a single command.

## Install and test

Use Python 3.12 and an independently installed Blender 5.2.1. All commands below run from the repository root. Numerical work needs no account, network service or GPU after installation.

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r toolkit/requirements.txt
.venv/Scripts/python -m pip install -r toolkit/requirements-face.txt
$env:BLENDER = (Get-Command blender).Source
$env:CHARFORGE_SCRATCH = Join-Path $env:TEMP 'charforge-toolkit'
$env:TEMP = $env:CHARFORGE_SCRATCH
$env:TMP = $env:TEMP
New-Item -ItemType Directory -Force $env:TEMP | Out-Null
.venv/Scripts/python -B -m unittest discover -s toolkit -t . -v
.venv/Scripts/python -B verify.py
```

The full suite requires Blender and the optional face runtime; missing dependencies are errors, not skipped successes. Math-only users can omit the face requirements and use the numerical modules independently. The face extra installs an external OpenCV wheel whose movie decoder has separate LGPL notices; no codec is redistributed here. The tests use the existing public assets in the three challenge folders and analytic counterexamples generated in memory. Tests delete their own temporary outputs. Native fitting requires at least 40 GiB free. Keep generated media outside the distribution and remove only files generated by your run.

## Modules

| Module | Available tools | Challenge use |
|---|---|---|
| [qa](qa/README.md) | C1–C7 surface/contact/deformation metrics, trace evaluator, analytic and native falsifiers; C8 via face | Score independently measured traces; diagnose failed contact |
| [gait](gait/README.md) | Phase-matched, leg-normalized geometry and full-body naturalness descriptors | Compare a candidate to an explicit licensed reference |
| [preflight](preflight/README.md) | Eight native rest/static-pose predictors and [failure catalogue](preflight/FAILURE-PATTERNS.md) | Find structural causes before retargeting |
| [rig](rig/README.md) | Landmarks, skeleton fit, graph weights, corrective helpers, IK/contact/root/arm math | Build an experimental rig or improve motion fixes |
| [layers](layers/README.md) | Inner-body warp, conservative voxel proxy, visible-shell partition adapter | Explore hidden-body reconstruction without inventing visible anatomy |
| [secondary](secondary/README.md) | Body-scaled presets, fixed-step spring lattice, capsule collisions | Test hair and garment response against explicit collision proxies |
| [face](face/README.md) | Feature extraction, native UV erasure, atlases, face shader, C8, mouth likeness | Repair duplicate features and detect mouth-style drift |

[Portable skills](skills/README.md) describe each stage's manifest and review contract. The intake, image-generation, mesh-generation and final engine-import stages require user-supplied tools; no unavailable automatic pipeline is advertised. The numerical tools and optional Blender adapters in this folder are independently callable.

## Evidence and limits

Coordinates are metres, Z up; procedural rig geometry uses X left and Y back. Height in centimetres is mandatory for fitting and physical presets. Preserve source orientation, landmark uncertainty, contact intent, reference hashes and missing observations. An unavailable metric must remain unavailable. A saved rig, finite solver or passing synthetic case is not production acceptance.

QA thresholds are provisional engineering bands. Gait comparisons and preflight predictions are advisory. The existing challenge scorers remain frozen; the newer face gate here is C8/10 and must not silently replace the challenge's C8/6. Gate changes need a passing control and a failing counterexample, followed by visual inspection. This test suite proves the listed mathematics and public-asset integrations; it does not establish full four-body, animal, Unity or Unreal acceptance.

`SOURCE-MAP.json` records source digests for adapted original code. `IMPORTS.json` inventories each Python import and its dependency class. See [LICENSES.md](LICENSES.md) for external runtime terms. No binaries, models, character assets or copied third-party implementations are included in this folder.

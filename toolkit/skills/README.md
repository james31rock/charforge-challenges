# Portable skills

Each folder contains an independent `SKILL.md`. Install or point your skill runner at the folder, keep the toolkit distribution available, and run commands from the repository root. The top-level `charforge` skill describes the full manifest chain; numerical and Blender adapter skills invoke the included modules. Stages relying on external image, mesh or engine tools say so explicitly.

- [charforge](charforge/SKILL.md): Use the toolkit to plan and review a reproducible character pipeline.
- [charforge-intake](charforge-intake/SKILL.md): Declare views and physical scale before modelling.
- [charforge-views-faces](charforge-views-faces/SKILL.md): Complete a consistent turnaround and approved expression/mouth edits.
- [charforge-mesh](charforge-mesh/SKILL.md): Obtain a mesh from reviewed views and retain generation provenance.
- [charforge-mesh-qa](charforge-mesh-qa/SKILL.md): Check scale, geometry and observable landmarks before binding.
- [charforge-rig](charforge-rig/SKILL.md): Fit a candidate humanoid skeleton, weights and correctives.
- [charforge-preflight](charforge-preflight/SKILL.md): Predict structural motion failures from a native rig.
- [charforge-layers](charforge-layers/SKILL.md): Fit an inner collision body and partition visible shells.
- [charforge-face](charforge-face/SKILL.md): Build and validate a layered face while preserving design.
- [charforge-motion](charforge-motion/SKILL.md): Apply deterministic contact, knee, root and arm corrections to licensed motion.
- [charforge-gait-compare](charforge-gait-compare/SKILL.md): Compare explicit reference and candidate gait geometry.
- [charforge-secondary](charforge-secondary/SKILL.md): Simulate body-scaled hair and outfit chains deterministically.
- [charforge-acceptance](charforge-acceptance/SKILL.md): Evaluate measured motion and face evidence before delivery.
- [charforge-export](charforge-export/SKILL.md): Review Blender and engine exports after upstream acceptance.

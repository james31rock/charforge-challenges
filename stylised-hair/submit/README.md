# Submit a reproducible hair fix

Provide `walk.npz` and `jump.npz`, each with the single array `hair` described
in the challenge README, plus your solver script or patch and reproduction
instructions. Include all dependency and asset licences. Do not modify the
scorer, fixed drive or measurement membership to obtain a PASS.

Run `python score.py submit/my-entry --json result.json` from the challenge
directory. Include the resulting report and full walk/jump visual evidence.
Reviewers regenerate the report from your data. Entrant code is never imported
by the scorer; source review precedes isolated scratch execution.
